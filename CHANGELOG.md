# Changelog

## v3.0.0 — WebSocket вместо MQTT (миграция с Yandex IoT Core)

### ⚠️ Зачем обновляться

Яндекс закрывает сервис **Yandex IoT Core**, через который версии 2.x получали команды Алисы:

- **1 ноября 2026** — голосовые команды и управление из приложения на версиях 2.x **перестанут работать** (состояния и датчики продолжат отправляться);
- **1 декабря 2026** — Yandex IoT Core отключается: с этого момента полноценно работают **только версии 3.0.0 и новее**.

Версия 3.0.0 от IoT Core не зависит. **Обновитесь до 1 ноября 2026.**

### Что изменилось

- **Транспорт команд**: MQTT (`mqtt.cloud.yandex.net:8883`, пароли устройств) → WebSocket (`wss://ws.nodered-home.ru/v1/ws`, авторизация тем же OAuth-токеном Яндекса, что и остальные запросы).
- **Зависимости**: `mqtt` заменён на `ws` — пакет стал легче.
- **Сеть**: исходящее подключение на стандартный порт **443** вместо 8883 — проще за файрволами и корпоративными прокси.
- **Надёжность**: keep-alive ping/pong, автоматический реконнект с экспоненциальным backoff (1–60 с) и джиттером.
- **Мультиинстансы**: до 5 одновременных подключений Node-RED под одним аккаунтом — в MQTT-версии инстансы с одним clientId вытесняли друг друга.

### Обновление

Прямо из интерфейса Node-RED: меню → **Управление палитрой** (Manage palette) → вкладка **Ноды** → найдите `node-red-contrib-alice` → **Обновить**, затем перезапустите Node-RED.

Альтернатива через npm:

```
cd ~/.node-red
npm install node-red-contrib-alice@latest
```

**Переавторизация и перенастройка не требуются**: флоу, настройки нод и существующая авторизация Яндекса продолжают работать. Ноды устройств и умений не менялись — обновляется только служебная нода подключения.

### Совместимость

- Node.js ≥ 14, Node-RED ≥ 3.0
- Формат сообщений на входах/выходах нод не изменился
- Версии 2.x продолжат работать до 1 ноября 2026, дальше — только датчики/состояния, без голосовых команд
